# Q1 Python 唯一实现计划（规范化第二轮）

## 实现目标

以根目录 `model_assumptions.md` 为唯一数学口径，实现带确定性角度误差的交会定位区域、凸多边形直径和直径端点圆覆盖判定。运行汇总必须记录该文件的 SHA-256；摘要、旧图片和论文笔记不得覆盖其中的定义。

## 决策与范围

- 实现语言：Python 3。
- 实验轮次：`round2`，保留 `round1` 作为历史证据。
- 决策标识：`q1_model_assumptions_canonical_2026-09-11`。
- 主方法：角域半平面求交、Andrew 单调链凸包、旋转卡壳最远点对。
- 可用基线：在同一凸包上枚举全部顶点对，时间复杂度为 O(m^2)。
- 不实现概率误差、拟合定位、目标圆裁剪、接收半径、频道、移动或模拟器接口。

## 输入契约

输入 JSON 包含：

```json
{
  "observations": [
    {"x": 0.0, "y": 0.0, "bearing_deg": 30.0}
  ],
  "delta_deg": 1.0,
  "tol": null
}
```

- `observations` 至少包含一条记录。
- 坐标单位为米，必须是有限实数。
- `bearing_deg` 单位为度，允许任意有限实数，内部归一化到 `[0,360)`。
- `delta_deg` 必须满足 `0 < delta_deg < 90`。
- `tol` 省略或为 `null` 时采用尺度相关容差。

## 输出契约

输出状态为 `OK`、`DEGENERATE`、`EMPTY` 或 `UNBOUNDED`，并包含逆时针顶点、直径、直径端点、直径圆覆盖结果及诊断信息。仅 `OK` 和 `DEGENERATE` 返回有限直径。诊断至少记录候选/可行/拒绝交点数、尺度容差、凸包面积；有限区域还记录最大约束违反量，无界区域记录一个可行的齐次方向见证。

## 计算步骤

1. 每条观测转换为两条叉积半平面约束。
2. 枚举边界直线交点并保留满足全部约束的点。
3. 检查齐次约束是否存在非零公共方向，从而识别无界区域。
4. 对可行交点容差去重并求凸包。
5. 主方法用旋转卡壳计算直径，基线枚举所有顶点对。
6. 断言两种直径在容差内一致。
7. 以直径端点中点为圆心、半径为直径一半，检查全部凸包顶点。

## 与算法参考图片的对应关系

三张算法图中的“非线性规划”“最小二乘法/非线性拟合”和“蒙特卡洛模拟”与 Q1 有一定联系，但角色不同：

- 非线性规划可以把可行点和最远点对写成连续约束优化问题，但本题是二维凸几何，直接枚举边界交点并用旋转卡壳求直径更精确、透明且无需优化器。
- 最小二乘或非线性拟合可以根据多条中心示向线估计一个位置点，但会丢失题设 `±1°` 确定性误差对应的完整可行区域，因此不作为正式主算法。
- 蒙特卡洛模拟适合做随机核验和敏感性分析。本轮使用固定随机种子生成凸多边形，检验旋转卡壳与暴力枚举的一致性；它不替代定位区域的解析构造。

正式算法属于计算几何：角域半平面求交、凸包、旋转卡壳。算法图片没有直接列出这些名称，不能为追求表面对应而改用不符合输出要求的拟合或优化方法。

## 风险与检查

- 0°/360° 环绕：使用正弦、余弦和叉积，不比较角度区间端点大小。
- 近似平行边界：行列式绝对值不超过 `1e-12` 时不求交。
- 数值尺度：绝对几何容差默认为 `1e-9` 乘坐标及候选交点尺度。
- 退化区域：点或线段单独返回 `DEGENERATE`。
- 输出退化：必须记录候选交点、可行交点、凸包面积及主基线差异。
