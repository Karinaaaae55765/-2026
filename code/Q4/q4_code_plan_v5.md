# Q4 V5代码计划：低源数联合重构

## 目标与口径

V5针对真实演练中11—12源平均时间明显高于16源的问题重构。首要约束仍为100%清除和严格停止；480秒/源是团队优化目标，不是题面阈值。程序不得读取`enter`返回或测试文件中的真实源数。

## 主方法

1. 使用原点、半径1875m的12点外环和半径950m的12点错相内环组成25点严格候选。Delaunay剖分与圆域相交部分最大边约988.440m，小于最小接收半径1000m。
2. 覆盖、Q2第二检测点和清除任务进入同一任务池，以移动、检测、切频、清除的虚拟时间估计作代价；不再保留未调用的“名义联合调度器”。
3. 每到证书点，先集中扫描UNKNOWN频道，再对无需额外移动且交会角合适的DETECTED频道补测。
4. 单示向源优先使用锚点对称及楔形中部侧向候选；外环近径向示向只允许最多320m的短楔形试探，失败后立即转Q2补测。完整1500m楔形仅作严格后备。
5. `no_signal`按频道保存。连续几何证书负责严格ABSENT判定；位置—方向角箱消去量只参与候选排序，绝不作为未经证明的提前退出依据。
6. 达到16个已发现/清除源时使用题面数量上界排除剩余频道；否则必须完成连续几何证书。

## 基线、验证和失败口径

- 主方法：`Q4-V5-LOW-COUNT-JOINT`。
- 基线：`Q4-V4-DYNAMIC`，同场景、同随机种子直接比较。
- 验证覆盖10—16源、全定向、混合源、圆周朝外、未知源数泄漏和调度器真实调用。
- 重点报告10—12源池化秒/源，同时报告16源退化比例。
- 任一场景漏源、严格停止失败或运行时读取真实源数即判失败；性能目标未达成必须单独标记，不得改写为成功。

## 风险与后备

- 25点模板减少空频道检测，但12点外环对极端圆周朝外源的多示向能力弱于V4的18点外环，因此保留短楔形和Q2补测。
- 动态证书数值验证失败时补扫V3严格三角网格。
- 主动补测耗尽且仍为单示向时，才允许调用完整窄楔形覆盖。
