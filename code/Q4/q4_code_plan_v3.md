# Q4 V3 代码计划：未知源数严格证书版

## 唯一实现口径

- 运行期间不知道干扰源总数；不得读取 `/enter` 中的源数，也不接受命令行源数。
- 20 个频道分别维护 `UNKNOWN / DETECTED / CLEARED / ABSENT` 状态。
- 单点 `no_signal` 不裁剪定向源位置；`ABSENT` 只能由覆盖圆域的全部相交三角形三顶点无信号证书推出。
- 只有全部 20 个频道均为 `CLEARED` 或 `ABSENT`，且清除数位于 10 至 16，才允许正常 `/exit`。

## 主方法 Q4-V3-UNKNOWN

1. 采用边长 950 m 的等边三角网格，验证边长严格小于最小接收半径 1000 m。
2. 在必须访问全部证书顶点的约束下，综合总路程和三角单元前缀完成度生成静态路线。
3. 每个顶点只扫描仍为 `UNKNOWN` 的频道；一旦得到正响应，该频道退出全域搜索队列。
4. 已发现频道在后续证书顶点最多顺路补测若干次，优先形成大交会角；顺路补测不增加移动距离。
5. 全域扫描后，将证书完整的未知频道标记为 `ABSENT`。
6. 对剩余 `DETECTED` 频道全局滚动调度补测、可恢复试清除和严格包围圆清除任务，避免逐频道长距离往返。

## 基线与验证

- 基线：Q4-BASE，全部网格顶点固定扫描全部 20 个频道，再定位清除。
- 对照：Q4-V2-FALLBACK，仅用于衡量旧版未知源数路径，不作为新版主方法。
- 固定种子 2026；覆盖 10 至 16 源、全定向、混合源和边界不利方向。
- 首要门槛是每次 100% 清除与严格停止；480 秒/源只作为优化目标，不写成题面要求。

## 风险与回退

- 定向源可能只在三角形一个顶点可见，所以不能删去证书顶点。
- 顺路补测可能得到 `no_signal`，只记录结果，不据此错误排除位置。
- 若定位任务超过上限或严格停止失败，程序报错且不调用正常退出，不伪造成功。
